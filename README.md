# GLYPH ASCII Studio

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18018。

## 终端发布器（04 / TERMINAL PUBLISHER）

把当前字符作品适配到具体终端并导出可 `cat` 的彩色文件，同时提供模拟终端检查。

- **目标终端**：VT100 80×24 / xterm-256 132×43 / iTerm2 190×50 / 移动 42×22 / dumb TTY。
  选择后自动套用该终端的列宽、行数、色彩能力与字符宽度规则，列宽也可再微调。
- **两种适配方式，各自保留布局版本**：
  - `整图重采样`：把整幅裁剪图按目标宽度重新采样，保持宽高比，缩放后完整显示（必要时留白，不裁切）。
  - `窗口平移`：原网格按 1:1 密度取景，只显示目标能容纳的范围，用方向键平移查看原细节。
  两份布局（整图版 / 窗口版）同时保存，切换方式不会丢弃另一份。
- **色彩能力**：24 位真彩色、256 色、16 色、无颜色。有限色使用 CIE Lab 最近色匹配，
  版本比较页给出各目标的色差（ΔE 均值、P95）与输出体积，便于权衡。
- **字符宽度规则**：自动（东亚双宽）/ 窄字符 / 宽字符。双宽字符占两列，组合符紧随基字符占零列。
- **导出**：`下载终端文件`（`.ansi.txt`）、复制、`.sh` 脚本。颜色以 SGR 序列写入，
  不计入列宽；每行补齐到目标列宽并保留行尾空格；每行结束与文件结尾都写样式复位。
- **安全**：自定义字符中的控制字节（ESC、C0/C1、行分隔符等）在进入网格前被转为可见记号
  （如 `␛`），不会执行终端指令。
- **模拟终端**：从导出字节出发重放终端效果，校验「不折行、不裁切、最宽行不超过目标列宽、
  去掉样式序列后与确认网格逐字符一致、结尾样式复位」。去除样式序列后的内容与目标确认的
  网格精确对应，任何差异都会在检查条中列出。
- 切换目标、列宽、色彩能力或宽度规则后，来源采样、字符布局、模拟画面、文件内容与下载内容
  一起更新（同一 revision）。
